# Archive

`locus-osint.html` is a self-contained, single-file prototype of an earlier
project (LOCUS — "OSINT Location Workbench"). It is kept here only for
reference.

Waypoint is a deliberate departure from that direction:

- **LOCUS** explored OSINT-style aggregation of location intelligence.
- **Waypoint** is a consent-first location-sharing app. Sharing is always
  user-initiated, time-limited, and revocable. The public map is for
  *places and services* (water, shelter, hazards), never about
  individuals.

Nothing in this folder is loaded, imported, or built by the Waypoint app.
